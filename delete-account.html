Padam profil Barber PRO

Halaman rasmi untuk pemadaman profil dan data Barber PRO.

Padam dari aplikasi

  1. Buka Barber PRO.
  2. Pilih tab Profil.
  3. Pilih Padam Akaun.
  4. Semak maklumat dan sahkan pemadaman.

Profil, tempahan, ganjaran, ulasan dan barber kegemaran akan dipadam serta-merta.

Jika anda tidak boleh membuka aplikasi

Versi semasa tidak mempunyai akaun pelayan atau pangkalan data jauh. Oleh itu, tiada data akaun Barber PRO disimpan pada server. Memadam data aplikasi atau menyahpasang aplikasi akan membuang data demo pada peranti.

Data yang mungkin dikekalkan

Tiada data akaun pelayan dikekalkan dalam versi semasa. Jika ciri backend diperkenalkan kemudian, halaman ini akan dikemas kini dengan proses permintaan luar aplikasi dan tempoh pengekalan yang berkaitan.
